## 📖 Overview
**Malek CSS Interactive Lab** is a comprehensive, interactive learning tool designed to help developers and designers master CSS properties visually. It provides a real-time, side-by-side visualization of CSS rules, empowering users to adjust sliders, pick colors, and toggle layout behaviors while instantly generating clean, syntax-highlighted CSS code ready to be copied and pasted.

## ✨ Features
- 🎛️ **Interactive Controls**: Adjust CSS properties (Dimensions, Typography, Borders, Colors, Layouts) with intuitive sliders, pickers, and toggles.
- 🧩 **Flexbox Playground**: A dedicated space to explore all Flexbox properties (`flex-direction`, `justify-content`, `align-items`, etc.) with a live visual playground.
- 💻 **Live CSS Output**: Get syntax-highlighted CSS code generated in real-time.
- 🌓 **Dark & Light Mode**: Seamlessly switch between elegant light and dark themes.
- 🌐 **RTL / LTR Support**: Fully supports both Left-to-Right (English) and Right-to-Left (Arabic) directions.
- 📏 **Box Model Visualization**: Interactive Box Model guides to visually understand Margin, Padding, and Content zones.
- 🎨 **Gradient & Z-Index Visualizers**: Specialized tools to learn how gradients and stacking contexts work.

## 🛠️ Tech Stack
This project is built with pure, vanilla web technologies to ensure maximum performance and accessibility without heavy dependencies:
- **HTML5** - Semantic and accessible structure.
- **CSS3** - Advanced custom properties (variables), Grid, and Flexbox for the UI design system.
- **JavaScript (Vanilla)** - DOM manipulation, state management, and real-time CSS generation.

2. **Navigate to the directory:**
   ```bash
   cd CSSPRO
   ```
3. **Run the app:**
   Simply open `index.html` in your favorite modern web browser. No local server or build steps required!

## 📖 نظرة عامة
**مختبر CSS التفاعلي (Malek CSS Interactive Lab)** هو أداة تعليمية وتفاعلية شاملة صُممت لمساعدة المطورين والمصممين على إتقان خصائص CSS بشكل بصري. تتيح لك الأداة معاينة التغييرات في الوقت الفعلي أثناء تعديل الخصائص، مع توليد أكواد CSS جاهزة للنسخ واللصق فوراً.
